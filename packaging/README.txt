F/A-18 Hornet 2.0 on modern computers
=====================================

This download is a build of Systemless (https://github.com/benletchford/systemless)
with the patches from https://github.com/mitoyarzun/fa18-hornet-mac.

It contains no game files. Supply your own copy of F/A-18 Hornet 2.0 as a
StuffIt archive (.sit), a MacBinary file (.bin), or an HFS disk image
(.toast, .iso, .img, .dsk). The installer disc image works directly.

macOS
-----
1. Remove the download quarantine. Run this in Terminal, in this folder:
       xattr -dr com.apple.quarantine .
2. Start the game:
       ./run-hornet.sh "/path/to/F-A-18 Hornet 2.0.toast"

Windows
-------
1. Drag your game archive onto run-hornet.cmd.
2. If SmartScreen stops the program, click "More info", then "Run anyway".

Controls, known issues and the full instructions are in the project README:
https://github.com/mitoyarzun/fa18-hornet-mac
