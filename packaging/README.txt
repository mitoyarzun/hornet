F/A-18 Hornet 2.0 on modern computers
=====================================

This download contains no game files. You need your own copy of
F/A-18 Hornet 2.0 as one of these files:

  - a StuffIt archive (.sit)
  - a MacBinary file (.bin)
  - a disk image of the game disc (.toast, .iso, .img, .dsk)

The disk image of the installer disc works directly.

Start the game
--------------
macOS:   double-click "F-A-18 Hornet".
Windows: double-click "F-A-18 Hornet.exe".

At the first start, select your game file. The launcher remembers it, so the
next starts go directly to the game. The game asks for the serial number
from your Pilot Flight Manual one time.

If the game file moves, the launcher asks for it again. To use a different
file on Windows, drag it onto "F-A-18 Hornet.exe".

First start on macOS
--------------------
The app is not signed by a registered Apple developer, so macOS blocks the
first start.

1. Double-click "F-A-18 Hornet". macOS shows a warning. Click "Done".
2. Open System Settings, then Privacy & Security.
3. Scroll down and click "Open Anyway" next to "F-A-18 Hornet".
4. Enter your password, then click "Open Anyway" again.

Do this one time only.

First start on Windows
----------------------
If SmartScreen stops the program, click "More info", then "Run anyway".
Do this one time only.

Controls and help
-----------------
The mouse is the control stick. Put it in the center of the screen before you
increase thrust. Press Delete to set thrust to 100%. Each next press of
Delete adds one afterburner stage. The Space bar is the brake.

For all controls and known issues, see:
https://github.com/mitoyarzun/hornet
